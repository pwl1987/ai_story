错误: 系统记录每个阶段的输入、输出和执行状态

### 2.2 违规详情

#### ❌ 缺少具体指标 (27项, 41.5%)

**定义:** NFR中未包含数字、百分比或比较符(> < =)

**典型示例:**

| 行号 | NFR ID | 内容 | 问题 |
|------|--------|------|------|
| 756 | R2 | 单个服务组件故障不得导致整个系统崩溃(隔离性) | 缺少故障隔离时间指标 |
| 764 | R7 | 数据库事务失败必须回滚,保持数据一致性 | 缺少回滚时间指标 |
| 769 | R9 | 生成的图片和视频文件必须正确存储,不得丢失 | 缺少容错率指标 |
| 770 | R10 | Redis故障时系统必须降级到数据库轮询模式(降级机制) | 缺少切换时间指标 |
| 771 | R11 | Celery故障时API必须返回"任务已提交"消息,避免用户等待 | 缺少响应时间指标 |
| 974 | S3 | API密钥不得记录在日志文件中 | 缺少验证方法 |
| 1020 | UX3 | 前端响应式设计 | 缺少响应式断点指标 |

**修正建议:**
```
错误: 单个服务组件故障不得导致整个系统崩溃
正确: 单个服务组件故障必须在5秒内被隔离,不影响其他服务

错误: 生成的图片和视频文件必须正确存储,不得丢失
正确: 生成的文件必须有99.9%的存储可靠性,支持自动恢复

错误: 前端响应式设计
正确: 前端必须支持1920px、1366px、768px三种分辨率断点
```

| 732 | P3 | 前端首屏加载时间必须 < 3秒(基于标准网络) | 缺少网络标准定义 |
| 733 | P4 | 实时进度推送延迟必须 < 500ms(WebSocket到前端) | 缺少测量方法 |
| 734 | P5 | API调用超时必须在30秒后触发指数退避重试(1s→2s→4s),最多3次 | 缺少验证方法 |

**修正建议:**
在NFR下方添加子项目:
```
- **NFR-P1:** API请求必须在500ms内响应(P95) - 排除AI API延迟

  - 验证标准: 使用Apache Bench进行压力测试,1000个请求中P95 < 500ms
  - 测试工具: ab -n 1000 -c 10 http://localhost:8000/api/v1/projects/
```
