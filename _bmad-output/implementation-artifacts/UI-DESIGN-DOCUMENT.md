## 🎨 UI 设计规范

### 颜色方案

**daisyUI 主题配置:**
```javascript
// daisyUI 主题
- primary: 蓝色 (强调色)
- secondary: 紫色 (次要色)
- accent: 青色 (高亮色)
- neutral: 灰色 (中性色)
- info: 青色 (信息)
- success: 绿色 (成功)
- warning: 黄色 (警告)
- error: 红色 (错误)
```

### 组件库

- **daisyUI 4.12.23** - UI 组件库
- **Tailwind CSS 3.4.17** - 工具类 CSS
- **Heroicons** - 图标库
