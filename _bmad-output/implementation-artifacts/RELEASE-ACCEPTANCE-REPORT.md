### BLK-1: 服务层命名冲突 (🔴 严重)

**问题描述:**
- `apps/artworks/services.py` (批量操作服务)
- `apps/artworks/services/` (ComfyUI/Script Parser 服务)
- Python 无法区分模块和包，导致导入冲突

**影响:**
- 22 个测试用例无法运行 (fixture 错误)
- 15 个测试用例失败 (导入错误)

**修复方案:**

```bash
# 方案1: 重命名 services.py 为 batch_operations.py
mv apps/artworks/services.py apps/artworks/batch_operations.py

# 然后更新所有导入
# from apps.artworks.services import BatchOperationService
# 改为:
# from apps.artworks.batch_operations import BatchOperationService
```

**预估工作量:** 1-2小时

### BLK-2: 安全漏洞 (🔴 严重)

**问题描述:**
```
Package: djangorestframework-simplejwt
Version: 5.3.1
Vulnerability: 1 known vulnerability
Details: https://data.safetycli.com/p/pypi/djangorestframework-simplejwt/97c/
```

**修复方案:**

```bash
# 更新到最新版本
uv add "djangorestframework-simplejwt>=5.3.2"
```

**预估工作量:** 5分钟

### BLK-3: 测试覆盖率不足 (🟡 中等)

**问题描述:**
- 当前覆盖率: 68%
- 目标覆盖率: ≥80%
- 缺口: 12%

**建议优化:**
1. 修复服务层导入问题，恢复 22 个错误测试
2. 修复 15 个失败测试
3. 为未覆盖的代码路径补充测试

**预估工作量:** 4-6小时
