## 📋 Part 1: 当前流程分析

### 1.1 现有工作流回顾

**当前的5阶段流程**：

```
用户输入主题
    ↓
1. 文案改写 (rewrite) - AI重写文本
    ↓
2. 分镜生成 (storyboard) - AI生成场景列表
    ↓
3. 文生图 (image_generation) - AI生成场景图片
    ↓
4. 运镜生成 (camera_movement) - AI生成镜头指令
    ↓
5. 图生视频 (video_generation) - AI生成视频片段
    ↓
输出: 完整视频
```

### 1.2 痛点识别

**问题收集**（请确认或补充）：

1. 🔴 **无法编辑AI生成的内容**
   - 现象：AI生成的分镜不满意，只能全部重来
   - 影响：浪费时间和API调用成本
   - 期望：能够手动编辑分镜，或单场景重新生成

2. 🔴 **执行过程不透明**
   - 现象：一键全跑，看不到中间过程
   - 影响：用户焦虑，无法及时调整
   - 期望：实时显示进度，支持暂停/继续

3. 🔴 **内容一致性问题**
   - 现象：同一角色在不同场景长相不同
   - 影响：视频专业度下降
   - 期望：角色、场景、道具的资源库管理

4. 🟡 **无法复用成功配置**
   - 现象：每次项目都要从零开始
   - 影响：重复劳动，效率低
   - 期望：保存成功的配置为模板

5. 🟡 **缺少质量控制**
   - 现象：生成后才发现逻辑矛盾
   - 影响：需要手动检查
   - 期望：自动一致性检查

## 💡 Part 3: 业务需求深入讨论

### 3.1 资源管理的业务场景

**场景1: 用户创建新项目**

```
用户流程：
1. 输入主题："古代武侠故事"
2. 系统提示：是否使用资源库？
   - 选项A：使用平台预设（快速）
   - 选项B：从个人资源库选择（复用）
   - 选项C：创建新资源（定制）

用户选择：
- 角色：从平台库选择"古代剑客"模板
- 场景：从个人库选择"江南小镇"
- 风格：选择"水墨武侠风"
```

**问题讨论**：
1. 这个流程是否合理？
2. 需要哪些额外的引导或提示？
3. 如何平衡"快速上手"和"深度定制"？

---

**场景2: 用户编辑分镜**

```
用户场景：
用户查看AI生成的分镜，发现场景3不满意

当前痛点：
- 只能全部重来，浪费时间和API调用
- 无法只修改场景3

期望流程：
1. 点击场景3的"编辑"按钮
```

**问题讨论**：
1. 编辑界面需要哪些功能？
2. 如何确保修改后的一致性？
3. 是否需要AI辅助优化？

### 3.2 资源继承机制

**三级资源架构**：

```
平台级（系统预设）
    ↓ 可继承 + 可覆盖
用户级（个人资源库）
    ↓ 可继承 + 可覆盖
项目级（项目专属）
```

**继承规则讨论**：

**问题1**: 用户创建项目时，如何选择资源？

**选项A**: 全部手动选择
- 优点：完全控制
- 缺点：操作繁琐

**选项B**: 智能推荐 + 手动调整
- 优点：AI根据主题自动推荐
- 缺点：推荐可能不准确

**选项C**: 模板化预设
- 优点：一键应用完整配置
- 缺点：灵活性较低

**您倾向于哪种方式？或者有更好的想法？**

---

**问题2**: 资源的覆盖逻辑？

例如：用户在平台级选择了"古代剑客"角色，但在项目级需要修改

**选项A**: 克隆一份到项目级
- 优点：互不影响
- 缺点：数据冗余

**选项B**: 引用 + 覆盖配置
- 优点：节省空间
- 缺点：实现复杂

**您觉得哪种更合适？**
