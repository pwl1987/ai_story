## Part 2: 功能需求详细规格

### FR-1: 资源管理系统

#### FR-1.1: 资源层级管理

**用户故事**:
```
作为用户，
我想要在平台、个人和项目三个层级管理资源，
这样我可以在新项目中复用成功配置，同时在项目中自由定制。
```

**功能需求**:

**FR-1.1.1 平台级资源库**
- 系统预设资源（开箱即用）
- 官方维护，定期更新
- 所有用户可见但只读
- 用户可以克隆到个人库或项目

**FR-1.1.2 用户级资源库**
- 用户私有资源
- 可以从平台级克隆后修改
- 可以完全自定义创建
- 可以跨项目复用

**FR-1.1.3 项目级资源库**
- 项目专属资源
- 从平台级或用户级克隆
- 完全独立，修改不影响源
- 随项目一起导出/归档

**验收标准**:
- [ ] 用户可以浏览平台级资源库
- [ ] 用户可以克隆资源到个人库
- [ ] 用户可以克隆资源到项目库
- [ ] 修改项目资源不影响源资源
- [ ] 删除项目不影响用户和平台资源

---

#### FR-1.2: 角色资源库

**用户故事**:
```
作为内容创作者，
我想要定义角色的外观、服装、性格等特征，
这样AI生成的视频中的角色始终保持一致。
```

**数据模型**:
```python
Character:
    - 基本信息: name, display_name, gender, age
    - 外观描述: appearance, height, body_type
    - 服装: default_outfit, accessories
    - 性格: personality, mannerisms
    - 声音: voice_description
    - 参考图片: reference_images[]
    - 一致性配置:
        - visual: face_seed, hair_color, eye_color
        - poses: default, emotions
        - scene_rules: {battle, rain, night}
```

**功能需求**:

**FR-1.2.1 创建角色**
- 手动填写角色信息
- 上传参考图片（最多5张）
- 使用AI辅助生成描述
- 设置一致性参数（seed、颜色等）

**FR-1.2.2 编辑角色**
- 修改任何字段
- 添加/删除参考图片
- 调整一致性配置
- 保存版本历史

**FR-1.2.3 角色应用到项目**
- 将角色添加到项目
- 设置角色重要性（主角/配角/背景）
- 设置首次出场场景
- 分配道具给角色

**FR-1.2.4 角色一致性检查**
- 检查角色在所有场景中的一致性
- 报告不一致的生成结果
- 提供修复建议

**验收标准**:
- [ ] 可以创建并保存角色
- [ ] 角色可以在项目中应用
- [ ] 同一角色在不同场景中视觉一致
- [ ] 支持参考图片上传和管理

#### FR-1.3: 场景资源库

**用户故事**:
```
作为用户，
我想要保存场景模板（如"江南水乡古镇"），
并设置不同时间、天气的变体，
这样可以在不同项目中快速复用。
```

**数据模型**:
```python
SceneResource:
    - 基本信息: name, scene_type
    - 环境描述: environment, atmosphere
    - 时间设定: time_of_day, weather
    - 视觉元素: architecture_style, color_palette, key_elements
    - 推荐镜头: recommended_shots[]
    - 参考图片: reference_images[]
    - 一致性配置:
        - visual: style_seed, art_style
        - time_variations: {morning, noon, dusk, night}
        - weather_variations: {sunny, rainy, snowy}
```

**功能需求**:

**FR-1.3.1 场景时间/天气变体**
- 定义同一场景在不同条件下的表现
- 自动调整光照、氛围、颜色
- 保存为变体配置

**FR-1.3.2 场景应用到分镜**
- 将场景分配给特定场景号
- 覆盖默认时间/天气设置
- 自动应用视觉一致性参数

**验收标准**:
- [ ] 场景可以定义时间/天气变体
- [ ] 同一场景在不同场景号中视觉一致
- [ ] 支持参考图片上传

**用户故事**:
```
作为用户，
我想要控制每个阶段的执行时机，

```

**验收标准**:
- [ ] 可以逐阶段控制执行

### FR-4: 智能辅助系统

#### FR-4.1: AI辅助模式

**用户故事**:
```
作为用户，
我想要选择AI辅助的程度，
这样我可以根据自己的技能水平调整自动化程度。
```

**功能需求**:

**FR-4.1.1 三种辅助模式**

**🟢 全自动模式** (适合新手)
- AI主导决策
- 用户主要负责确认
- 适用场景: 快速生成，不追求完美

**功能示例**:
```
用户输入: "古代武侠故事"

AI自动:
1. 选择风格预设: "水墨武侠风"
2. 创建角色: 自动生成"古代剑客"角色
3. 创建场景: 自动生成"江南水乡"场景
4. 执行工作流: 自动执行全部5个阶段
5. 用户确认: 每步只需点击"确认"

配置选项:
- ☑️ 自动选择风格预设
- ☑️ 自动创建角色
- ☑️ 自动创建场景
- ☑️ 自动执行全部阶段
```

**🟡 辅助模式** (平衡模式)
- AI提供建议
- 用户做决策
- 适用场景: 有一定经验，希望控制

**功能示例**:
```
用户输入: "古代武侠故事"

AI建议:
- 风格: ["水墨武侠风", "写实武侠风", "动漫武侠风"]
  推荐: 水墨武侠风 (匹配度: 95%)
- 角色: 建议创建"古代剑客" (已存在于个人库)
- 场景: 建议使用"江南水乡" (已存在于个人库)

用户选择:
- ✅ 水墨武侠风
- ✅ 古代剑客
- ❌ 江南水乡 (改为"蜀山")

执行:
- AI基于用户选择继续提供建议
- 用户确认每个关键步骤
```

**🔴 手动模式** (专业模式)
- 用户完全控制
- AI仅执行指令
- 适用场景: 专业用户，精细控制

**功能示例**:
```
用户操作:
1. 手动创建角色 (填写所有字段)
2. 手动配置场景
3. 手动设置每一步参数
4. 手动触发执行

AI角色:
- 仅在用户明确请求时执行
- 如: "帮我润色这段文本"
```

**FR-4.1.2 模式切换**
- 项目级别设置辅助模式
- 阶段级别可以临时调整
- 可以在执行中切换模式

**验收标准**:
- [ ] 支持三种辅助模式
- [ ] 全自动模式AI决策合理
- [ ] 辅助模式建议准确
- [ ] 手动模式完全可控
- [ ] 模式切换流畅

**验收标准**:
- [ ] 检查覆盖4个维度
- [ ] 问题定位准确率 > 95%
- [ ] 修复建议可行性 > 80%

## Part 4: 验收标准

### AC-1: 资源管理

**Given** 用户已登录
**When** 用户创建新项目
**Then**
- 系统提示选择资源方式
- 用户可以浏览平台/个人资源库
- 用户可以克隆资源到项目
- 项目资源独立，修改不影响源

### AC-2: 分镜编辑

**Given** 用户已完成分镜生成
**When** 用户编辑场景3的旁白
**Then**
- 编辑内容实时保存
- 可以撤销/重做
- 其他场景不受影响
- 可以标记场景为"已修改"

### AC-3: 单场景重生成

**Given** 用户对场景3不满意
**When** 用户选择重新生成场景3
**Then**
- 仅场景3重新生成
